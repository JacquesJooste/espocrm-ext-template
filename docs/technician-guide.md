# Technician guide

Eligible queue records show an Elevate panel on detail and quick-detail screens and a stopwatch launcher in lists.

- **Report In** confirms the attending internal users and starts a server-timed session.
- **Mark Milestone** completes a selected Work Block, records the time since the last checkpoint, and accepts an optional Work Note or flag.
- **We're Done** completes the final block or asks for segment times when several blocks remain.
- **Manual Time Entry** records historical start/end times and attendees.

A Scheduled Start is required. Starting before that time is allowed but visibly flagged. Work exceeding its estimate by more than one hour requires a Reason for Drag. Custom reasons require a Work Note.

Elapsed time is clock duration. Labour time is elapsed duration multiplied by attendee count.

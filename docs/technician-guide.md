# Technician guide

The target record remains the primary working screen. Eligible records show a responsive Time Management card with the active timer, next Work Item, schedule, assigned resources, weighted progress, elapsed time, and labour time.

Use the two primary actions:

- **Log Time** selects the Work Item and attending users, then starts a server-timed session. The current user is selected by default. Manual entry is available inside this dialog as the secondary method.
- **Work Blocks** attaches, reviews, schedules, assigns, or reschedules work.

While a timer is active, Log Time becomes **Stop Timer** and shows live elapsed time. When stopping, choose whether the Work Item remains in progress or is complete.

The stopwatch in a target list opens Log Time directly; it no longer navigates to the detail record first. Mobile actions are full width and at least 48 pixels high.

Use **Reschedule Remaining Work** when unfinished items must move. The extension creates a linked future schedule slot and moves only unfinished Work Item runs. Completed work and existing Time Entries remain on the original slot.

Elapsed time is clock duration. Labour time is elapsed duration multiplied by the number of attending technicians. A team therefore shares one Time Entry while preserving total labour.

My Work lists the current timer and upcoming assigned Work Items.
